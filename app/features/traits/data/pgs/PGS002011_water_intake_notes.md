Practical note for this project:

- This is a consumer-facing nutrition trait, but it should be read cautiously as an inherited panel-relative water-intake signal rather than a direct readout of current hydration behavior.
- The local empirical reference artifact validates successfully on the current panel with the standard intake profile of `20%` minimum overlap and `10` matched variants.
- The current local reference includes `31` samples out of `33` screened files, which is a solid starting point for the no-imputation workflow.
- Real-world water intake depends strongly on climate, activity, fasting, body size, diet, health status, and routine, so the output should stay descriptive rather than deterministic.
