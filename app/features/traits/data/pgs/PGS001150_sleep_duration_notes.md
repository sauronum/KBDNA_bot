Practical note for this project:

- This is a consumer-facing lifestyle trait, but it should be read cautiously as an inherited panel-relative sleep-duration signal rather than a direct readout of current sleep hours.
- The local empirical reference artifact validates successfully on the current panel when built with a relaxed-but-explicit threshold profile of `10%` minimum overlap and `100` matched variants.
- Real-world sleep duration depends strongly on work schedule, stress, family routine, age, illness, medication use, travel, and sleep hygiene, so the output should stay descriptive rather than deterministic.
